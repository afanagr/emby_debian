# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют
[Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-20

Первый публичный релиз.

### Добавлено

- подключение к Emby по API-ключу или логину и паролю, автоматический вход по
  сохранённому токену;
- навигация по библиотекам, папкам, сериалам, сезонам, альбомам и плейлистам;
- поиск по всей библиотеке;
- очередь воспроизведения, перемотка, громкость, повтор и перемешивание;
- воспроизведение видео внутри виджета и в отдельном окне поверх остальных
  (включая Wayland);
- отправка прогресса просмотра на сервер;
- настройки подключения и воспроизведения;
- общие компоненты `ToolTipButton`, `SeekSlider`, `VolumeSlider` и `MediaRow`;
- скрипт `scripts/check.sh` для проверки QML и структуры пакета;
- GitHub Actions workflow для автоматической проверки QML и KPackage.

### Исправлено

- видео внутри виджета больше не замирает, если popup-представление виджета
  открывалось ранее: скрытый предзагруженный экземпляр больше не перехватывает
  видеовыход;
- кнопка раскрытия popup в компактном представлении использует
  `Plasmoid.activated()` вместо несуществующего `Plasmoid.expanded`.
